# Pregnancy Dashboard

A privacy-first Next.js dashboard for pregnancy/TTC tracking.

## Current MVP
- Multiple pregnancy/TTC timelines
- Gestational age calculated from LMP
- Estimated due date calculated from LMP (editable)
- Appointment log
- Doctor question queue + answers
- Cycle history
- Local browser storage (no database yet)

## Run in Codespaces or locally
```bash
npm install
npm run dev
```

Then open the forwarded port for localhost:3000.
